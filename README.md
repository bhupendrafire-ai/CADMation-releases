# CADMation for Windows

Official CADMation Windows installers and release notes.

**[Download the latest installer](https://github.com/bhupendrafire-ai/CADMation-releases/releases/latest)**

Choose the `CADMation_NXT_v…_Setup.exe` asset. GitHub's automatically generated source archives contain this repository's download documentation, not the application.

CADMation 0.3.21 and later can download verified updates automatically and install them after the app safely closes. Use **Tools → Updates** to check, pause or enable updates. Older versions need a one-time installation of 0.3.21 or later.

This repository contains installers and public release notes only. The application source is maintained privately. Customer projects, BOMs, drawings and credentials are not stored here.
